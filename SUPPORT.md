# Get support

LilRAE is community supported on a best-effort basis.

Use GitHub issues for reproducible defects, focused feature requests, and
documentation problems. Use the private route in [SECURITY.md](SECURITY.md) for
suspected vulnerabilities.

Include the LilRAE and RAES versions, Python and operating-system versions, the
smallest command or input that reproduces the problem, and expected versus
actual behavior.

## Backend execution boundary

The engineering baseline supports installation, import, help, version, build,
and clean-artifact verification only. It does not yet provide backend execution,
runtime lifecycle commands, conformance, hosted operation, or production
support.

Questions about RAES semantics, contracts, schemas, or protocols belong in the
[RAES repository](https://github.com/RAESystem/rae). LilRAE support covers only
the concrete capabilities this repository truthfully declares.

There is no commercial support channel or response-time commitment.
